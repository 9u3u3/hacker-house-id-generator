## 1. What this project is

A web tool for **Hacker House Goa 2026, Open Trial Task #1 — Frame / ID Card
Generator**. A user uploads a photo, fills in a few fields, and gets a branded
"Tide Pass" builder ID card they can download as a PNG or share to X.

The card's gimmick: it is **lenticular**. Tilt left for sunrise, right for
blacklight/night. The night face carries a secret line of text that exists nowhere
else, so the only way to read it is to tilt the card.

**Stack:** Next.js 16 (App Router, Turbopack) · React 19 · Tailwind v4 ·
TypeScript. Canvas is the only renderer — the tilt UI, the download, and the share
image all come from the same canvases in `src/lib/card/draw.ts`.

**Read `README.md` for the architecture.** It is unusually good and explains why
things are the way they are.

## 8. Known traps

These cost the previous session real time to find. Do not rediscover them.

- **`npm run check:mobile` asserts on decoded pixels, not the DOM.** It exists
  because the card once rendered *completely blank* on a real phone while every
  screenshot looked fine. A background change is exactly the kind of thing that
  breaks it. **Run it immediately after the backdrop lands.**
- **The card must stay the hero.** The backdrop sits behind a green scrim
  (`--hh-green` at ~0.82) plus a vignette. If the card or form text loses
  contrast, the scrim is too weak. Verify on a phone viewport, not just desktop.
- **The three card plates are ~700KB combined** and gate the first render.
  `src/lib/card/assets.ts` loads them via `new Image()` behind a shared promise
  cache — that part is fine; what's missing is `<link rel="preload">`. That's item 5.
- **`useTilt` publishes tilt as CSS custom properties from inside a rAF loop** and
  deliberately never enters React state — a `setState` per frame would re-render
  the studio at 60fps. If you add backdrop parallax, read those same CSS vars.
  Do not add state.
- **Respect `prefers-reduced-motion`** — the existing code does, throughout.
- **Transparency in exports renders as white bars on X.** Two separate bugs put
  transparency into the export before; `scripts/flow.ts` asserts zero transparent
  pixels. Don't introduce `destination-out` compositing near the card background.
